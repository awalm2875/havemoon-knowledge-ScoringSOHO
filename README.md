# Havemoon Knowledge Base

Source repository for **Havemoon – China Sourcing & Manufacturing Knowledge Base**.

Havemoon publishes independent, practical guidance for overseas buyers and importers working with suppliers and manufacturers in China.

## Content areas

- Sourcing basics
- Supplier verification
- Quality control
- Manufacturing
- Logistics and Incoterms
- Compliance
- Product sourcing guides
- Buyer resources and practical tools

## Local development

Requirements: Node.js 22+, Bun, Python 3, FontTools, and Brotli.

```bash
bun install
bun run dev
```

Production build:

```bash
bun run build
```

## Editorial approach

Content is written for practical buyer decisions. Regulatory, customs, and compliance topics should be checked against current primary sources before publication.
